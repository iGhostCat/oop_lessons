# Проект "Введение в ООП"

## Описание:
Проект содержит заготовки под анализ складских запасов различных товаров и работу с БД

## Установка:

1. Клонируйте репозиторий: 
```
git clone https://github.com/iGhostCat/oop_lessons.git
```

2. Разверните виртуальное окружение проекта:
```
pip install poetry
poetry shell
```
3. Проведите тестирование корректности работы представленного функционала:
```
pytest
```
